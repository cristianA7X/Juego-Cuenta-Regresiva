# Cuenta Regresiva

Juego de escritorio de supervivencia y toma de decisiones hecho en **Java Swing**.
Trabajo Práctico Integrador de *Desarrollo de Sistemas Orientados a Objetos* (2.º año,
Tecnicatura Superior en Desarrollo de Software, ISFT Municipal "Leopoldo Marechal").

Suenan las sirenas: tenés 60 segundos para recorrer la casa, juntar provisiones y llevar
a tu familia al refugio. Después hay que sobrevivir 15 días racionando agua y comida y
tomando decisiones ante lo que pasa cada día.

## Cómo ejecutarlo

1. Abrir NetBeans → **File → Open Project** → elegir la carpeta `60-seconds`.
2. **Run** (F6). La clase principal es `presentacion.Main`.

## Organización

| Paquete | Capa |
|---|---|
| `presentacion` | Interfaz gráfica (Swing): pantallas y componentes |
| `logica` | Dominio y reglas del juego |
| `persistencia` | Almacenamiento en memoria con `ArrayList` |
